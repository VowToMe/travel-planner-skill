# Travel Preferences Template

此文件是可选的本地模板。默认不要复制真实偏好到公开仓库。

```text
YYYY-MM-DD  出发城市：未填写
YYYY-MM-DD  常用交通：未填写
YYYY-MM-DD  单日驾驶上限：未填写
YYYY-MM-DD  旅行节奏：未填写
YYYY-MM-DD  预算习惯：未填写
YYYY-MM-DD  住宿偏好：未填写
YYYY-MM-DD  饮食限制：未填写
```

规则：

- 一行一个稳定事实，前置日期。
- 只记录用户明确要求长期保留的信息。
- 新信息覆盖旧信息时，在原行更新并标记日期，不保留两份冲突记录。
- 不记录证件号、手机号、邮箱、支付信息、精确住址或同行人的敏感信息。
